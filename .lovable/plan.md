## 목표
작업허가서 양식 기능의 기준을 하나로 정리합니다. 기준은 **표준양식 스타일**이며, 사용자가 작업허가서를 작성할 때 보이는 화면, 미리보기, 인쇄, 로고, 결재서명, PDF 오버레이/자유 빌더가 서로 따로 놀지 않도록 같은 데이터와 같은 렌더러를 사용하게 만듭니다.

## 현재 확인된 구조
- `허가서 양식 디자인` 화면에는 `표준양식 스타일`, `원본 PDF 오버레이`, `AI 자동 분석`, `자유 빌더`, `빌더 미리보기`가 모두 별도 탭으로 존재합니다.
- `표준양식 스타일` 미리보기는 `DigPermitForm`을 직접 렌더링합니다.
- 작업허가서 작성 화면도 표준 양식일 때는 `DigPermitForm`을 사용하지만, 별도 템플릿이 선택되면 `OverlayFillForm`으로 분기됩니다.
- `빌더 미리보기`는 `LivePreview`를 사용하며, 현재 표준양식 스타일 기준의 실제 SF003 화면이 아니라 자유 빌더용 일반 폼 미리보기입니다.
- 로고는 `standard_style.logoUrl`에 저장되도록 되어 있으나, 작업허가서 작성 화면에서는 종류별 템플릿 선택/탐색 로직에 따라 저장한 스타일이 일관되게 선택되지 않을 수 있습니다.

## 정립 방향
작업허가서 양식 시스템을 다음 3계층으로 정리합니다.

```text
1. 표준양식 스타일 = 기본/주력 방식
   - 일반 / 밀폐 / 화기 / 굴착별 스타일
   - 셀 색상, 행 높이, 열 너비, 로고, 문서번호, 승인업체명
   - 작성 화면 / 미리보기 / 인쇄가 모두 동일 렌더러 사용

2. 원본 PDF 오버레이 = 고급 출력 방식
   - 업로드한 PDF 위에 입력값/서명값만 얹는 특수 출력 옵션
   - 표준양식 스타일과 혼동되지 않게 고급 기능으로 분리

3. 자유 빌더 = 보조/레거시 기능
   - 표준 SF003을 대체하지 않음
   - 미리보기 명칭과 위치를 정리하거나 숨김 처리
```

## 구현 계획

### 1. 작성 화면과 표준양식 미리보기의 폭/셀 계산 통일
- `DigPermitForm` 자체에 A4 기준 폭/인쇄 폭을 안정적으로 적용할 수 있는 wrapper 옵션을 추가합니다.
- `StandardStyleEditor`의 실시간 미리보기와 `WorkPermitDetail` 작성 화면이 같은 A4 폭, 같은 padding, 같은 table-layout 조건에서 렌더되도록 맞춥니다.
- 작성 화면의 외부 카드/패딩 때문에 표가 늘어나거나 열 너비가 왜곡되지 않도록 표준 렌더 컨테이너를 공통화합니다.

### 2. 로고 저장/반영 경로 고정
- 로고는 `layout_json.standard_style.logoUrl`을 단일 저장 위치로 유지하되, 작업허가서 작성 화면에서 현재 허가서 종류의 기본 표준양식 스타일을 확실히 불러오도록 템플릿 선택 로직을 정리합니다.
- `general`, `confined_space`, `hot_work`, `excavation` 각각의 스타일이 있으면 해당 종류를 우선 적용하고, 없을 때만 공통/general 스타일로 fallback합니다.
- 저장 후 목록 재조회 시 선택 중인 템플릿의 최신 `standard_style`이 즉시 화면에 반영되도록 selected/layout 상태 동기화를 정리합니다.

### 3. 표준양식 스타일을 “양식 디자인의 기준 화면”으로 승격
- `허가서 양식 디자인` 화면의 기본 탭은 계속 `표준양식 스타일`로 유지합니다.
- `빌더 미리보기`는 현재 자유 빌더용이므로 혼란을 줄이기 위해 다음 중 하나로 정리합니다.
  - 명칭을 `자유 빌더 미리보기`로 변경하고 고급 영역 아래로 이동
  - 또는 표준양식 기준 미리보기로 교체
- 표준양식 스타일 탭의 미리보기가 실제 작성 화면과 같은 컴포넌트, 같은 컨테이너를 쓰도록 합니다.

### 4. 원본 PDF 오버레이와 표준양식 스타일의 관계 정리
- 원본 PDF 오버레이는 표준양식 스타일을 대체하는 별도 양식이 아니라, “고급 출력용 PDF 배경 + 필드 매핑”으로 명확히 분리합니다.
- 작성 화면의 양식 선택 드롭다운에서 다음처럼 구분합니다.
  - `표준 SF003 양식` — 표준양식 스타일 적용
  - `원본 PDF 오버레이 양식` — 업로드 PDF 기반
- PDF 오버레이 선택 시에는 표준양식 스타일 셀 너비/색상과 일치해야 한다는 혼선을 없애고, PDF 자체가 기준임을 UI상 명확히 합니다.

### 5. 서명/결재라인 자동 표시 일관화
- 표준양식 작성 화면의 서명칸은 전자결재 완료 후 이름/승인일/서명이 자동 표기되도록 현재 매핑을 유지하되, 표준양식 미리보기에도 동일한 샘플 결재 데이터를 넣어 실제 출력 모습을 확인할 수 있게 합니다.
- PDF 오버레이도 같은 결재라인 매핑 키를 사용하도록 `signature_role` 기준을 통일합니다.

### 6. 템플릿 선택 로직 단순화
- 작업허가서 작성 화면은 기본적으로 `표준 SF003 양식`을 사용합니다.
- 마스터가 등록한 PDF 오버레이 템플릿은 별도 선택 가능한 고급 템플릿으로만 노출합니다.
- 표준양식 스타일은 드롭다운에서 선택하지 않아도 현재 permit type에 맞게 자동 적용되도록 합니다.

### 7. 검증
- 일반 / 밀폐 / 화기 / 굴착 탭 각각에서 다음을 확인합니다.
  - 디자인 화면 실시간 미리보기와 작성 화면 셀 폭 일치
  - 로고 저장 후 작성 화면 반영
  - 셀 색상/행 높이/열 너비 반영
  - 결재 완료 데이터가 서명란에 자동 표시
  - 인쇄 시 작성 화면과 동일한 A4 레이아웃 유지

## 결과물
- 작업허가서 양식 디자인의 기준은 `표준양식 스타일`로 통일됩니다.
- 작성 화면, 미리보기, 인쇄 화면이 같은 표준 렌더링 경로를 사용합니다.
- PDF 오버레이/자유 빌더는 고급/보조 기능으로 정리되어 혼란을 줄입니다.
- 저장한 로고와 스타일이 실제 작업허가서 작성 화면에 즉시 반영됩니다.
