
# 허가서 양식 디자이너 & 원본 충실 인쇄

JSON 편집을 없애고, 비개발자도 마우스로 만드는 양식 디자이너로 교체합니다. 인쇄는 원본 PDF/이미지 위에 값만 얹는 픽셀 단위 오버레이 방식으로 바꿉니다. 점검표·TBM·사고보고서 등 다른 양식 확장은 이 1단계가 안정화된 다음에 같은 엔진을 재사용해 확장합니다.

---

## 1단계 — 이번에 만들 것 (허가서만)

### A. 비주얼 폼 빌더 (`/settings/permit-forms`)
사용자가 보는 화면:
- **좌측**: 양식 목록 (현재 그대로 유지)
- **중앙(편집기)**: 섹션 카드들이 위→아래로 배치. 각 섹션 안에 필드 카드들이 그리드로 배치.
- **우측 속성 패널**: 선택된 섹션 또는 필드의 속성을 폼으로 편집 (라벨/필수/너비/타입 등).
- **상단 툴바**: [섹션 추가] [필드 추가] [미리보기] [원본PDF 업로드] [저장]

지원 필드 타입:
- 텍스트 / 멀티라인 텍스트
- 날짜 / 날짜범위 / 시간
- 숫자 / 단위
- 체크박스 / 체크박스 그룹 (SF003 식 항목 체크)
- 라디오 / 드롭다운
- 표 (행/열 정의, 셀별 라벨)
- 서명란 (담당/검토/승인 — 결재선 자동 매핑)
- 첨부파일 (위험성평가/작업계획서/기타)
- 자동값 (오늘 날짜, 시공사, 발주사, 작성자 등)

조작: 드래그로 순서 변경, 우클릭으로 복제/삭제, Ctrl+Z 되돌리기. JSON은 "고급 보기"에 접어둠 (마스터가 원할 때만 열림).

### B. 원본 PDF 위 오버레이 (픽셀 인쇄)
사용자가 보는 흐름:
1. 양식 편집화면에서 **"원본 PDF 업로드"** → SF003 원본을 올림.
2. 화면이 **좌측 원본 미리보기 / 우측 필드 목록**으로 전환.
3. 원본 위에서 마우스로 사각형을 그려 그 자리가 어떤 필드(예: `permit_date`)인지 선택 → 좌표 저장.
4. 체크박스도 같은 방식으로 "이 사각형은 `gas_check=true`일 때 ✓" 매핑.
5. 결재 서명란은 "역할(담당/안전관리자/소장)"로 매핑 → 결재 완료 시 자동 채워짐.

저장 데이터: `template.print_overlay = { pdf_url, pages:[{ boxes:[{field_key, x,y,w,h, page, render:"text|check|signature|image"}] }] }`.

인쇄 시:
- `generate-permit-pdf` 엣지함수가 **원본 PDF를 베이스로 열고**, 각 박스 위치에 값/체크/서명 이미지를 합성.
- 결과물은 원본과 픽셀 단위로 동일. 결재 이력 페이지는 마지막에 자동 첨부.

### C. 데이터 모델 변경
- `permit_form_templates`에 `print_overlay jsonb`, `original_pdf_url text` 추가 (기존 `layout_json` 유지 — 디자이너가 출력).
- 디자이너 변경분에 대한 **버전 스냅샷** (`permit_form_template_versions`) — 결재된 허가서는 발급 당시 버전을 그대로 보존.

### D. 운영/권한
- 마스터: 표준 양식(SF003) 수정 가능.
- 프로젝트 관리자: 프로젝트 전용 커스텀 양식 생성/수정 가능 (`project_id` 채움).
- 시공사: 사용만 가능.

## 2단계 — 다음에 확장할 것 (이번 작업 아님, 합의만)

같은 폼 빌더 + 오버레이 엔진을 재사용해 아래로 확장:
1. **점검표** (일일/주간/월간 안전점검) — 체크 결과가 `safety_inspections`에 자동 적재
2. **TBM 일지 / 교육 일지** — 참여자·서명·사진 자동 매핑
3. **사고/아차사고 보고서, 비상훈련 기록** — 법정 보고 양식
4. **완전 사용자 정의 양식** — "문서 양식 엔진"으로 통합

각 양식은 출력 대상 테이블(`document_target`)만 매핑하면 동일 디자이너에서 만들 수 있게 설계.

---

## 기술 메모 (개발자용)

- 빌더 UI: `react-dnd` 또는 `@dnd-kit/core` 사용. 기존 shadcn 컴포넌트 유지.
- PDF 오버레이 좌표 편집기: `pdfjs-dist`(이미 설치됨)로 페이지 렌더 → `<canvas>` 위에 절대좌표 박스. 좌표는 0~1 정규화 저장(해상도 독립).
- 인쇄 합성: 엣지함수에서 `pdf-lib`로 원본 PDF 위에 텍스트/이미지 draw. 한글 폰트(NotoSansKR) 임베드.
- 서명 이미지는 결재 완료 시 `approvals` 레코드의 `signature_url`을 박스 좌표에 합성.
- 마이그레이션: `print_overlay`, `original_pdf_url` 컬럼 + 버전 스냅샷 테이블 + Storage 버킷 `permit-form-assets` (private, 마스터/PM 쓰기, 인증사용자 읽기).
- 기존 SF003 표준양식은 한 번에 좌표 매핑해 시드.

---

## 이번 단계에서 안 하는 것
- 점검표/TBM/사고보고서 양식화 (2단계)
- 사용자 정의 신규 문서 카테고리 (2단계)
- 모바일에서의 양식 디자이너 (데스크탑 전용 유지)

승인해주시면 1단계만 바로 구현합니다.
