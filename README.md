# 오늘의 TBM — 24시간 자동으로 돌아가는 건설현장 안전교육 사이트/앱

매일 새벽 전국 24개 건설 거점의 기상예보를 받아 **폭염·강풍·강우·강설·한파 작업중지 기준**을 판정하고,
그날 그대로 읽으면 되는 **TBM(작업 전 안전점검회의) 대본 + 참석자 서명부**를 지역별로 자동 발행합니다.
갤럭시에서는 '홈 화면에 추가'로 앱처럼 설치됩니다(PWA).

## 왜 이걸로 돈이 되나 (사람들의 욕구)

| 욕구 | 이 서비스가 주는 것 |
|---|---|
| **귀찮음**: 관리감독자는 매일 아침 TBM 자료를 만들어야 함 | 버튼 한 번 복사 → 그대로 낭독 |
| **두려움**: 중대재해처벌법 — "안전교육 했다는 증거" 필요 | 날짜·지역이 박힌 서명부 인쇄 |
| **공유 본능**: 현장 단톡방에 매일 뭔가 올려야 함 | 📤 공유 버튼 → 매일 링크 확산(무료 바이럴) |

수익원(전부 합법, 승인/가입은 본인 명의로 직접 해야 함):
1. **쿠팡 파트너스** — 그날 위험요인에 맞는 용품(폭염→쿨토시·아이스조끼, 한파→핫팩, 우천→우의)을 자동 노출. 대가성 문구 자동 표기(공정위 지침).
2. **구글 애드센스** — 지역×날짜 아카이브 페이지가 매일 24개씩 쌓여 검색 유입이 복리로 늘어남(1년 ≈ 8,700페이지).
3. (확장) 건설사 대상 '우리 현장 전용 TBM' 유료 버전.

> 솔직한 기대치: 처음 1~3개월 수익은 거의 0원에 가깝습니다. 검색 노출과 단톡방 공유가 쌓여야 매출이 생깁니다.
> "매일 확정 수익"을 보장하는 프로그램은 존재하지 않으며, 그렇게 광고하는 것은 대부분 사기입니다.

## 자동 운영 / 자가 진화

- **24시간 무인 운영**: GitHub Actions가 매일 04:30, 11:30(KST)에 실행 → 테스트 → 생성 → 배포. 서버·전기·PC 불필요, 비용 0원.
- **자가 진화**: 페이지 제목 4가지 변형을 톰슨 샘플링으로 경쟁시킵니다. 공유 링크(`?v=변형`)로 들어온 조회수(GoatCounter)를
  매일 수집해 잘 퍼지는 문구가 점점 더 많이 쓰이고, 진 문구는 자동 도태됩니다. 상태는 `data/evolution.json`에 기록.
- **누적 자산**: 매일의 결과가 `data/history/`에 커밋되어 아카이브 페이지로 영구 발행.

## 최초 1회 설정 (클릭 몇 번)

1. **Settings → Pages → Source: GitHub Actions** 선택 (이것만 하면 사이트가 켜집니다)
2. **Actions** 탭 → `daily-tbm` → *Run workflow* (첫 실행; 이후는 자동)
3. 주소: `https://parkseoro.github.io/daily-tbm/` — 갤럭시 크롬/삼성인터넷에서 열고 *홈 화면에 추가*

수익화(선택, 본인 계정 필요):
- 쿠팡 파트너스 가입 → 상품 링크를 `config.json`의 `affiliate.heat` 등에 `{"name": "...", "url": "..."}`로 추가
- 애드센스 승인 후 `adsense_client`(`ca-pub-...`), `adsense_slot` 입력
- [GoatCounter](https://www.goatcounter.com) 무료 가입 → Settings → Variables에 `GOATCOUNTER_SITE`, Secrets에 `GOATCOUNTER_TOKEN` 추가 → 자가 진화 활성화

## 로컬 실행

```bash
python -m unittest -q                 # 판정 규칙 테스트
python -m tbm.build --fixture         # 네트워크 없이 가짜 기상으로 site/ 생성
python -m tbm.build                   # 실제 기상(Open-Meteo, 키 불필요)
```

## 판정 기준 (`tbm/hazards.py`)

- 폭염: 체감 31/33/35/38℃ → 관심/주의/경고/위험, 33℃↑ 2시간 이내 20분 이상 휴식
- 강풍: 순간풍속 10m/s 초과 타워크레인 설치·해체 중지, 20m/s 초과 운전 중지(안전보건규칙 제37조), 철골작업 중지(제383조)
- 강우 1mm/h·강설 1cm/h 이상 철골작업 중지(제383조), 한파 최저 −5/−10/−12℃

본 자료는 참고용이며 작업중지 등 최종 판단은 현장 관리감독자가 합니다.
