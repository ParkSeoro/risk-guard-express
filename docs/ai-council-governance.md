# 🏛️ SafeNex AI Council 무장애 관제 및 의회 거버넌스 체계

## 1. 개요
본 문서는 SafeNex(`risk-guard-express`)의 무장애 운영과 고신뢰성 배포를 위해 4대 AI가 유기적으로 협력하여 코드를 진단, 설계, 구현, 감사하는 **실체형 AI 의회(AI Council)** 운영 규격서입니다.

## 2. 4대 AI 전문 분업 구조
| AI 주체 | 역할 | 핵심 책임 |
| :--- | :--- | :--- |
| **🔷 Gemini Arbiter** | 총괄 의장 & 오케스트레이터 | 실시간 프로젝트 코드베이스 분석, 문제 근본 원인(RCA) 진단, 의제 도출 |
| **📐 Claude Architect** | 시스템 아키텍트 | 데이터 파이프라인 설계, 메인 UI 루프 블로킹 차단, 비동기 큐/마이크로태스크 분리 |
| **⚡ Cursor Builder** | 실무 코드 장인 | TypeScript 실무 구현 패치, 파일 직접 수정, Unified Diff 생성 |
| **🛡️ GPT Guardian** | 무장애 안전 감사관 | Golden Rules 3대 원칙(로그인, 결재, 소켓) 검증, Bun 테스트 실행 게이트 통과 |

## 3. Golden Rules (무장애 안전 감사 원칙)
1. **로그인/인증 무장애**: 인증 헤더 및 JWT 토큰 갱신, 세션 상태를 침해하는 코드 배포 불가.
2. **결재/트랜잭션 무결성**: 작업허가서(PTW) 및 안전 문서 승인은 지연 없이 단일 원자적 트랜잭션으로 커밋되어야 함.
3. **메신저 실시간성 보증**: WebSocket 채널 리커넥트 및 비동기 이벤트 분리로 소켓 끊김 0건 유지.
