# App Store Connect — 아이폰 앱 등록 (Safenex)

앱 아이디 `org.safenex.app`를 만든 뒤, **TestFlight에 올리기 전까지** 콘솔에서 채울 답만 모았습니다.  
빌드 명령과 Xcode 서명은 [`ios-app-setup.md`](./ios-app-setup.md)입니다. 이 환경에서는 애플 계정으로 로그인할 수 없어서, 아래는 직접 붙여 넣는 칸입니다.

등록에 쓰는 파일은 저장소에 있습니다.

| 파일 | 용도 |
| --- | --- |
| `ios/App/App.xcodeproj` | Xcode에서 열고 서명·보관(Archive) |
| `ios/App/App/Info.plist` | 표시 이름 Safenex, 한국어, 권한 문구, 수출 규정 아니오 |
| `ios/App/App/PrivacyInfo.xcprivacy` | 업로드 시 필요한 개인정보 목록. 추적은 없음 |
| `ios/App/App/Assets.xcassets/AppIcon.appiconset/AppIcon-512@2x.png` | 1024×1024 앱 아이콘 |

스크린샷은 아이폰에 설치한 뒤 찍습니다. 웹 화면을 늘려 만든 그림은 심사에서 거절됩니다.

---

## 1. 가입과 앱 만들기

1. [Apple Developer 등록](https://developer.apple.com/programs/enroll/)에서 **개인(Individual)** 로 가입합니다. 연회비 99달러. 사업자등록과 D-U-N-S는 쓰지 않습니다.
2. [Identifiers](https://developer.apple.com/account/resources/identifiers/list)에서 앱 아이디를 추가합니다. 종류는 App ID, 방식은 **명시적**, 번들 ID는 `org.safenex.app`입니다.
3. [App Store Connect](https://appstoreconnect.apple.com/apps) → 앱 → 신규 앱.

| 칸 | 값 |
| --- | --- |
| 플랫폼 | iOS |
| 이름 | Safenex |
| 기본 언어 | 한국어 |
| 번들 ID | org.safenex.app |
| SKU | safenex-ios |
| 사용자 액세스 | 전체 액세스 |

이름이 이미 있으면 `Safenex 현장안전`으로 바꿉니다. 번들 ID는 바꾸지 않습니다.

## 2. 앱 정보

[앱 정보](https://appstoreconnect.apple.com/apps) 왼쪽 **일반 정보 → 앱 정보**.

| 칸 | 값 |
| --- | --- |
| 부제 | 건설현장 안전관리 |
| 카테고리 | 비즈니스 |
| 보조 카테고리 | 없음 |
| 콘텐츠 권리 | 타사 콘텐츠를 포함하지 않음 |
| 연령 등급 | 설문은 모두 없음. 결과가 4세여도 **18세**로 올립니다. 현장 근로·관리자용입니다. |
| 가격 | 무료. 앱 내 구입 없음. 판매 국가 **대한민국** |

연령 설문에서 폭력, 성적 내용, 욕설, 도박, 공포, 주류, 의약품, 대회, 제한 없는 웹은 **아니오**입니다. 이 앱은 주소창이 있는 브라우저가 아닙니다.

## 3. 개인정보 처리방침과 앱 개인정보

처리방침 URL

```
https://safenex.org/privacy
```

[앱 개인정보](https://developer.apple.com/app-store/app-privacy-details/)에서 **수집함**으로 표시합니다. 추적(다른 회사 광고·데이터 중개)은 **아니오**입니다. 판매 목적 공유는 **아니오**입니다. 수집 목적은 앱 기능입니다. 전송 중 암호화와 계정 삭제 요청은 예입니다.

| 데이터 | 사용자에게 연결 | 추적 |
| --- | --- | --- |
| 정확한 위치 | 예 | 아니오 |
| 사진 | 예 | 아니오 |
| 이름 | 예 | 아니오 |
| 이메일 주소 | 예 | 아니오 |
| 전화번호 | 예 | 아니오 |
| 사용자 ID | 예 | 아니오 |
| 건강 | 예 | 아니오 |
| 제품 상호작용 | 예 | 아니오 |

건강은 현장 건강검진 기록입니다. 진단이나 치료를 제공하지는 않습니다. 연락처, 결제 정보, 브라우징 기록은 수집하지 않습니다.

## 4. 버전 1.1.9 소개 글

왼쪽 **iOS 앱 → 1.0 배포 준비**가 아니라, Xcode에서 올린 빌드 번호 `479`가 붙는 버전 칸입니다. 버전 문자열은 `1.1.9`입니다.

**홍보 텍스트**는 비워도 됩니다.

**설명**

```
SafeNex는 건설·플랜트 현장의 산업안전보건 운영을 위한 앱입니다.

■ 근로자
앱을 설치한 뒤, 현장에서 받은 등록 QR을 스캔해 가입하세요. 설치만으로는 가입할 수 없습니다. 가입 후 전화번호와 PIN으로 로그인합니다.

• GPS 현장 반경 출근·퇴근 및 작업·무재해·건강 서약
• 오늘 TBM 참여·전자서명
• 위험구역 진입 경보, 작업중지 요청

■ 관리자
• 안전작업허가서 전자결재·작업 완료 확인
• 위험성평가·작업계획서·TBM 진행
• 명부·교육·출입 이력 관리

관리자는 웹, 현장 인력은 모바일 앱으로 같은 시스템을 사용합니다.
개인정보처리방침: https://safenex.org/privacy
```

**키워드** (쉼표, 100자 이내)

```
안전,출퇴근,TBM,작업허가서,위험성평가,건설,현장,산업안전
```

**지원 URL**

```
https://safenex.org/manual
```

**마케팅 URL**

```
https://safenex.org/landing
```

**저작권**은 `2026` 뒤에 개발자 계정의 본인 이름을 적습니다. 예: `2026 홍길동`. 계정에 적힌 법적 이름과 같게 합니다.

**앱 심사 정보 → 로그인 필요**는 예입니다. 검수원이 쓸 계정은 본인이 만든 현장 계정의 이메일과 비밀번호를 적습니다. 이 저장소나 채팅에 비밀번호를 올리지 않습니다.

**메모**

```
건설 현장 안전관리 앱입니다. 유료 판매, 앱 내 구입, 광고는 없습니다.
로그인한 근로자가 출근 화면에서 위치를 켭니다. 백그라운드 위치는 근무 중 위험구역 진입을 알리기 위한 것이며, 사용자가 출근 화면에서 직접 허용합니다.
위치는 현장 밖으로 나가지 않는 안전 확인에 쓰이고, 광고나 판매에는 쓰지 않습니다.
수출 규정: 일반 HTTPS만 사용합니다. 자체 암호는 없습니다.
```

**연락처**는 심사 중 전화를 받을 본인 이름, 전화, 이메일입니다.

## 5. 스크린샷과 아이콘

아이폰 6.7인치(1290×2796 또는 1320×2868) **세로 2장 이상**. 근로자 홈과 출근 화면이면 됩니다. 아이콘은 Xcode 프로젝트의 1024 파일을 그대로 씁니다. 콘솔에 아이콘을 따로 올리는 칸이 있으면 그 PNG를 넣습니다.

## 6. 빌드를 올린 뒤

Mac이 없으면 [`ios-app-setup.md`](./ios-app-setup.md)의 「GitHub에서 올리기」로 TestFlight에 올립니다. 본인 Mac이 있으면 그 문서의 Mac 빌드로 Archive를 업로드합니다.

1. 빌드가 TestFlight에 나타나면 수출 규정은 **아니오**입니다. `Info.plist`의 `ITSAppUsesNonExemptEncryption`이 이미 아니오입니다.
2. 내부 테스터는 본인 Apple ID입니다. [TestFlight](https://developer.apple.com/testflight/)
3. 폰에서 로그인과 출근이 된 뒤에 심사 제출을 누릅니다.
4. 출시 방법은 수동입니다. 심사 통과 뒤 바로 스토어에 깔리게 두지 않습니다.

푸시 알림과 네이티브 QR 스캐너는 이 첫 등록에 넣지 않습니다. 절차는 `ios-app-setup.md` 8절입니다.

## 7. 막히면 채팅에 보낼 것

- 빨간 필수 항목 이름과 오류 문구
- 번들 ID가 `org.safenex.app`가 아니라는 메시지
- 서명 또는 Archive 실패 문구

비밀번호, 인증서 파일, `.p12`는 보내지 않습니다.
