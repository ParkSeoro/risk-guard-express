# Feature Cards

각 핵심 기능의 "완료 정의(Definition of Done)" 를 한 장에 모은 디렉토리입니다.

- `_template.md` 를 복사해서 `{기능명}.md` 로 추가합니다.
- 8개 체크리스트가 모두 체크되어야 그 기능을 "완료" 로 봅니다.
- PR 머지 전 리뷰어는 변경된 기능의 카드를 함께 검토합니다.

## 1차 사이클 코어 12개 기능

1. risk-assessment.md — 위험성평가 회차/항목
2. work-plan.md — 작업계획서
3. work-permit.md — 작업허가서
4. tbm.md — TBM 세션/QR
5. approvals.md — 통합 결재
6. incidents.md — 사고 보고
7. emergency-drills.md — 비상대피훈련
8. safety-cost.md — 산업안전보건관리비
9. worker-qr.md — 근로자 출입/QR
10. education-mapping.md — 교육 자동 매핑
11. inspections.md — 점검/시정조치
12. work-stop.md — 작업중지권
