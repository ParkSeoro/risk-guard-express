# K-엑사원 2.5를 SafeNex에 어디에 둘지

2026-11-19 결정. 이 문서는 배치만 정한다. 기본 라우트 [`supabase/functions/_shared/aiRoute.ts`](../supabase/functions/_shared/aiRoute.ts)는 바꾸지 않는다. 라우트, 설정 화면, 시크릿, 마이그레이션은 이 결정만으로 만들지 않는다.

상업 이용이 약관에 열리고, 키 만료·429·유료 단가 또는 서면 한도가 확인된 뒤에, 교육자료 한 경로만 `reasoning_effort=low` 그림자로 붙이는 구현을 따로 승인받는다.

## 모델

LG AI연구원이 2026-11-09에 API를 열었다. 호출은 OpenAI 호환 `POST https://api.exaone.ai/v1/chat/completions`, 모델 id는 `k-exaone_v2.5`이다.

- 텍스트만. 사진·도면·영수증 이미지는 받지 않는다.
- 한국어·영어. 공식 속도 등급은 Medium, 지능 등급은 Higher. 컨텍스트 512K. 지식 기준은 2026년 1월이라, 2026-11-04 위험성평가 지침은 프롬프트에 넣지 않으면 모른다.
- 추론을 끌 수 없다. `reasoning_effort` 기본값은 `max`이다. `max_tokens`에는 추론이 포함된다. 공식 예시에서 "Hello"는 답변 약 9토큰, 추론 209토큰이었다.
- 권장 샘플링은 `temperature=1.0`, `top_p=0.95`이다. 답변 `content`가 줄바꿈으로 시작할 수 있어, JSON을 쓰기 전에 trim이 필요하다.
- 검토 시점의 API 요금은 0원이다. 무료 종료일과 이후 단가는 문서에 없다. 키는 계정당 1개이고, 안내문 기준으로 30일 뒤 만료된다. 한도를 넘으면 429이다. 학습 데이터 동의는 선택이며, 동의하면 일일 한도가 늘어난다고 적혀 있다. 근로자 이름·보건·안관비 원문을 학습에 넘기지 않으므로 학습 동의는 켜지 않는다.
- 보도자료는 기업 서비스 개발·연구에 무료로 쓸 수 있다고 했다. 같은 시기 약관 해설은 비상업 이용만 허용하고, 내 제품에 붙여 제3자가 모델을 호출하게 하는 것을 금지한다고 전한다. 현장 문서에 붙이기 전에 [docs.exaone.ai](https://docs.exaone.ai)의 현재 이용약관을 확인한다. 보도자료만으로 운영 경로에 넣지 않는다.

## 유지하는 경로

짧은 JSON은 gpt-4o-mini, 긴 글·대화·이미지는 Gemini Flash-Lite와 2.5 Flash 비전. 이 분리를 유지한다.

- 위험성평가, 작업계획서, 허가서 브리핑, 사고사례. 짧은 JSON이고 스키마가 깨지면 재생성 비용이 더 크다. mini를 유지한다.
- OCR, 허가서 양식 분석, 안관비 영수증 사진. 텍스트 전용이라 대체할 수 없다.
- 보건·근로자 의견 분류. 입력이 짧고 개인정보가 있다. flash-lite를 유지한다.
- 상신 게이트, 근로자대표 협의 문장, 수시 사유, 법령 판정. 모델이 쓰지 않는다. 모델은 위험요인 초안과 빈칸 문장만 돕는다.

## 나중에 시험할 자리

약관이 현장 서비스 호출을 허용하고, 키 만료·429·유료 단가가 정해진 뒤에만 시험한다. 기본값으로 바꾸지 않는다. 시험하더라도 `reasoning_effort=low`만 쓴다.

- 1순위: 교육자료. 출력이 긴 한국어이고, 사용자가 읽은 뒤 저장한다. 지금은 Gemini flash-lite이다.
- 2순위: 안전 도우미 답변. 대화라 추론 이력이 길어질 수 있어, 이전 추론은 넘기지 않고(`preserve_thinking=false`) 답변만 이어 간다.
- 위험성평가 JSON 전체를 엑사원으로 바꾸지 않는다. 문장만 비교하려면 라이브러리 매칭 뒤 위험요인·대책 문장 초안에 한정하고, 적용 전에는 저장하지 않는다.

호출은 지금 OpenAI·Gemini와 같이 엣지 함수에서만 한다. 브라우저에 키를 두지 않는다. 실패·429·타임아웃이면 기존 provider로 돌아간다. 엑사원만으로 현장 버튼이 멈추면 안 된다.
