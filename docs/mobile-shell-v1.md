# Mobile Shell v1 (확정안 구현)

AAB 전에 PC **모바일 프리뷰**로 검수하는 것을 전제로 한 1차 골격입니다.

## 구조

| 탭 | 근로자 | 관리자 |
|----|--------|--------|
| 오늘 | 날씨 + 건강 + 출퇴근/TBM | 날씨 + 결재/조치/작업중지/현장인원 |
| 할 일 | 조치·TBM·사고·건강 | 점검·조치·사고·TBM·근로자 |
| 결재 | (탭 없음) | 통합 결재함 |
| 자료 | 허가서·위험성평가·작업계획 뷰어 | 동일 |
| 알림 / 더보기 | 공통 | 공통 |

- 모든 화면에 **작업중지** FAB
- 홈: `/app/worker/today` (구 `home`/`menu` 리다이렉트)

## 출입 정지

위치: **할 일/더보기 → 근로자 · 출입** (`MobileWorkers`)

- 기간: 1일 / 3일 / 영구 + 사유 필수
- RPC: `set_worker_site_entry_suspension`
- `worker_entry` 가 `SUSPENDED` 반환
- 근로자 오늘 화면에서 출근 버튼 차단

마이그레이션: `supabase/migrations/20260801180000_worker_site_entry_suspension.sql`

## 마스터 프리뷰 (PC)

경로: **설정 → 모바일 프리뷰** (`/app/admin/settings/mobile-preview`)

- 휴대폰 프레임 + 역할/프로젝트/기기 선택
- 실제 모바일 컴포넌트 재사용
- 쓰기 차단 (`PREVIEW · 데이터 변경 불가`)
- JWT 사칭 없음
