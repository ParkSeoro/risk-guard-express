# Play Console — 앱 생성 직후 채우기 (Safenex)

앱 만들기(`Safenex` / `org.safenex.app`)가 끝난 뒤, **내부 테스트 출시**까지 콘솔에서 할 일만 모았습니다.  
역할 구분: [`play-store-you-vs-me.md`](./play-store-you-vs-me.md)

---

## 1) 대시보드에서 남은 ★ 항목 순서

좌측 **정책 / 앱 콘텐츠** 쪽 미완료(★)를 아래 순서로:

1. 개인정보처리방침  
2. 앱 액세스  
3. 광고  
4. 콘텐츠 등급  
5. 타겟층 및 콘텐츠  
6. 데이터 보안  
7. 스토어 등록정보 (아이콘·설명·스크린샷)  
8. **테스트 → 내부 테스트** 에 AAB 업로드

## 2) 권장 답안 (복붙)

### 개인정보처리방침
```
https://safenex.org/privacy
```

### 앱 액세스
- **일부 기능 또는 전체가 제한됨** (로그인 필요)
- 테스트 계정: 실제 검수용 계정 이메일/비밀번호를 적어 주세요  
  (없으면 임시로 본인 관리자 계정 + “내부 테스트용” 메모)

### 광고
- **아니요**, 앱에 광고가 포함되어 있지 않습니다

### 콘텐츠 등급
- 설문: 비즈니스/생산성 도구  
- 폭력·성적·도박·마약 등 **모두 없음**

### 타겟층
- **만 18세 이상** (현장 근로·관리자용)  
- 아동 대상 아님  
- 뉴스 앱: **아니오**  
- COVID 접촉 추적: **아니오**

### 데이터 보안 (수집·공유)
수집한다고 표시할 항목(앱 기능 목적, **전송 중 암호화**, 삭제 요청 가능):

| 데이터 | 비고 |
|--------|------|
| 대략적 위치 / 정확한 위치 | 금지구역·현장 위치 |
| 사진 / 카메라 | 점검·증빙 촬영 |
| 이름, 이메일, 전화번호 | 계정·근로자 |
| 앱 활동 | 허가서·결재 등 업무 기능 |

- 판매 목적 공유: **아니오**  
- 금융·건강 민감 등 해당 없으면 체크하지 않음

## 4) AAB 받기 → 내부 테스트 업로드

### AAB 다운로드 (최신 main 기준 서명 빌드)
1. GitHub → **Actions** → 워크플로 **Android AAB**  
2. 최신 성공 run: [run 30786779135](https://github.com/ParkSeoro/risk-guard-express/actions/runs/30786779135) (`main` = PR #152 머지 시점)  
3. **Artifacts** → `safenex-1.0.0-450.aab` 다운로드 → zip 풀면 `app-release.aab`  
   - **구 빌드(8/1, `…-447`)는 쓰지 마세요.** 그 뒤로 기능이 많이 바뀌었습니다.

재빌드: `build/android-aab` 브랜치에 `main`을 push 하거나 Actions → **Android AAB** → **Run workflow**.  
Secrets(`ANDROID_KEYSTORE_*`)가 없으면 실패합니다.

### Play Console 업로드
1. **테스트 → 내부 테스트 → 새 버전 만들기**  
2. **Play 앱 서명 사용** (권장)  
3. `app-release.aab` 업로드  
4. 출시 노트 예: `최초 내부 테스트 빌드`  
5. 저장 → 검토 → **출시 시작**  
6. **테스터** 탭 → 이메일 목록 → **참여 URL** 공유  

테스터: 참여 URL → 「테스터 되기」→ Play Store에서 설치 (APK 직접 설치 금지).

첫 검토는 보통 **1~3일**.
