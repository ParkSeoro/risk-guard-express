# 사이드바 IA 정리 계획

이전 `Regroup sidebar` 이후에도 **사람** 그룹에 명부·QR·교육·관제맵·GPS가 한곳에 몰려 길어 보였음.

## 이번 패치 (1차 · 완료)

| 변경 | 내용 |
|------|------|
| 근로자 진입점 | 사이드바 4항목 → **근로자 관리** 1개 (`/workers`) |
| 레거시 QR | 일일 QR·게시판 QR 탭 제거 (딥링크는 등록 탭으로 안내) |
| 위치 분리 | 관제맵·구역·분포·추적점검 → **위치** 그룹 |

페이지 안 탭: **등록 정보** / **입퇴장 현황** 만 유지. 출근 SSOT = 앱 GPS.

## 2차 (다음)

1. **핵심** 그룹을 4개 유지하되 기본 펼침은 `priority`+`field`만, 나머지 접기 기본값
2. **위험/검증** 정리 — AI 어시스턴트·공지를 위험성평가 하위 또는 운영으로 이동 검토
3. **보건** — 대시보드 1개만 사이드바에 두고 나머지는 보건 대시보드 카드로 (근로자 관리와 동일 패턴)
4. **시스템** — 마스터 전용 항목을 「개발/진단」 접기 섹션으로 분리
5. 협력사 Foolproof 허용 URL을 새 IA에 맞게 재검증

## 원칙

- 사이드바 = **섹션 진입점** (탭/하위 화면을 나열하지 않음)
- 한 그룹 **최대 ~6항목**
- 미사용·레거시 기능은 숨기고 딥링크만 안내
