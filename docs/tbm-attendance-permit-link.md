# TBM · 출퇴근 · 허가서 연동 (합의안)

## 확정 정책 (단순화)

허가서 명단을 TBM/출근으로 **다시 맞추는 버튼은 쓰지 않습니다.**
허가서는 전날 **예상 배정**을 유지하고, 당일 실제 실시·서명은 TBM 일지에 남깁니다.

| 항목 | 결정 |
|------|------|
| 인원 (허가서) | **예상 배정**이 SSOT. TBM·출근으로 허가서를 덮어쓰지 않음 |
| TBM 명단 | 발행 시 예상 배정 → 미서명 참석자. 출근 서명이 붙으면 서명됨 |
| 출근 서명 | 배정된 허가서의 TBM에 서명. 배정이 없으면 **같은 회사 당일 TBM**에 서명 |
| 실출근 0명 | 허가서 배정을 지우지 않음 (버튼 자체가 없음) |
| 인쇄 | 승인 직후 가능 (이후 명단 변경과 무관) |
| TBM | **1 허가서 = 1 TBM**, 진입점 2개(허가서 상세 / TBM「허가서에서」) |
| AI | 브리핑 **초안만** |
| 서명 | 출근 후 배정 허가서+위험요지 **일괄 확인 후 서명 1번** → TBM 참여에 재사용 |
| QR | **선택**. 근로자 필수 경로가 아님 |
| 실시 사진 | TBM 세션에 현장 사진 최대 3장 (웹·앱) |
| 당일 인원 수정 권한 | 관리감독자·현장소장·안전관리자·프로젝트관리자·마스터 (예상 배정만) |

## 하루 흐름

```
[전날] 허가서 작성 → 예상 인원 배정 → 결재 승인 → (선택) 인쇄
      → 발행 시 당일 TBM 자동 생성 · 배정 명단을 TBM 참석자(미서명)로 넣음

[당일]
  · 근로자 「출근하기」서명 = 연결된 TBM 참석+서명
  · (배정 없이 출근한 경우) 소속 회사 당일 TBM에 서명
  · 관리자: TBM 일지에서 브리핑 수정 · 실시 사진 · 서명 확인 · 인쇄
  · QR은 필요하면 보조 도구로만
```

## 지운 것 / 남긴 것

| 동작 | |
|------|--|
| TBM으로 맞추기 (TBM → 허가서 덮어쓰기) | **삭제** (QR 시대 SSOT, 현장과 안 맞음) |
| 실출근으로 갱신 (출근자 → 허가서 → TBM) | **삭제** (두 단계 수동 맞춤) |
| 발행 시 TBM 자동 생성 | **유지** |
| 예상 인원 배정 | **유지** |
| 출근 서명 → TBM | **연동 강화** (배정 없으면 회사 당일 TBM) |
| 체크인으로 TBM 세션 생성 | **하지 않음** |

## DB

- `worker_daily_acks` — 당일 확인·서명
- `work_permit_workers` + `personnel_count` — 예상 인원

## TBM 일지 작성만 허가서 연동

- **「허가서에서」** / 허가서 상세 CTA → `ensureTbmForPermit` → RPC 링크
- 허가서 연동 TBM의 **주관자(`leader_name`)** = 허가서 작성자 (상신자 → form 작성자 → created_by)
- **「이전 TBM 불러오기」** → TBM 일지 폼 **내용만** 복사 (허가서 링크·근로자·서명·날짜 미복사)
- 허가서 화면에 이전 TBM 불러오기 없음
- 이미 생성된 TBM의 주관자는 소급 변경하지 않음 (신규 생성분만 적용)
