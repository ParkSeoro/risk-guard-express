# 그때살걸 — "그때 샀다면 지금 얼마?" 자동 운영 사이트·앱

날짜(생일·입사일·결혼기념일)만 넣으면 **그날 비트코인·이더리움 등을 샀다면 지금 얼마인지** 원화로 바로 계산합니다.
"매년 내 생일마다 10만원씩 샀다면?" 같은 **생일 적립 계산**도 됩니다.
갤럭시에서는 크롬/삼성인터넷 → *홈 화면에 추가*로 앱처럼 설치됩니다(PWA).

## 이용하는 욕구

| 욕구 | 장치 |
|---|---|
| **후회** — "그때 살걸" | 오늘 날짜 기준 1·3·5년 전 후회 랭킹을 매일 갱신 |
| **호기심·자기 이야기** — 내 생일이면? | 생일·기념일 입력 → 나만의 숫자 |
| **자랑·질투** — 친구에게 보여주고 싶음 | 결과 한 줄 + 링크를 카톡 공유(무료 확산) |
| **검색 습관** — "2021년 비트코인 100만원 지금" | 종목×월별 날짜표 페이지 약 1,000개 자동 생성, 매일 현재가로 갱신 |

## 24시간 무인 운영·자가 진화

- **GitHub Actions**가 매일 09:10·21:10(한국시간)에 업비트 시세 갱신 → 테스트 → 사이트 생성 → 배포. 서버·PC·비용 0원.
- **자가 진화**: 제목 4가지 심리 유형(후회/호기심/숫자/질투)을 톰슨 샘플링으로 경쟁시킵니다. 공유 링크(`?v=`)로 들어온
  조회수(GoatCounter)가 많은 유형이 점점 더 자주 쓰이고, 진 유형은 자동 도태됩니다(`data/evolution.json`).

## 수익 구조와 솔직한 기대치

- **구글 애드센스** — 방문자 수에 비례. 승인 후 `config.json`에 `adsense_client`, `adsense_slot` 입력.
- 거래소 추천인 링크는 넣지 않았습니다. 가상자산 광고는 「가상자산이용자보호법」 등 규제 위험이 있어 기본에서 제외했습니다.
- 초기 1~3개월 수익은 거의 0원입니다. 검색 노출과 카톡 공유가 쌓여야 광고 수익이 생깁니다. 매일 확정 수익을 보장하는 방법은 없습니다.

## 최초 1회 설정

1. GitHub에서 새 **public** 저장소 `geuttae` 생성 후 이 폴더 내용을 올리기
2. **Settings → Pages → Source: GitHub Actions**
3. **Actions** 탭 → *그때살걸 자동 갱신* → *Run workflow* (이후 자동)
4. 주소 `https://parkseoro.github.io/geuttae/` 를 갤럭시에서 열고 *홈 화면에 추가*
5. (선택) [GoatCounter](https://www.goatcounter.com) 무료 가입 → Settings → Variables에 `GOATCOUNTER_SITE`,
   Secrets에 `GOATCOUNTER_TOKEN` → 자가 진화 활성화

## 로컬 실행

```bash
python -m unittest -q          # 계산 테스트
python -m gl.build             # 업비트 시세 갱신 + site/ 생성 (첫 실행은 전체 이력 수집에 몇 분)
python -m gl.build --offline   # 저장된 시세로만 생성
```

## 기준

- 시세: 업비트 원화마켓 일봉 종가(한국시간 09:00 기준 일봉). 상장 전 날짜는 계산하지 않음, 거래 없는 날은 직전 종가.
- 금액 표기: 한국식(억·만원). 수수료·세금 미반영. 투자 권유 아님.
- 업비트 Open API 이용약관(상업적 이용 범위)은 운영 전 본인이 확인하세요. 문제가 되면 빗썸 공개 API로 교체할 수 있습니다.
